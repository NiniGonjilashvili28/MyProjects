# Billionaires Data Analytics — TBC GetData Final Project

## Overview

This is my final project for TBC IT Academy's **GetData: Data Analytics and Databricks SQL** program. It uses a dataset of the world's billionaires to practice the full analytics workflow: cleaning and preparing raw data, writing SQL queries to explore it, and building an interactive dashboard to present the findings.

## What's in this repo

- **`Billionaires Statistics Dataset.csv`** — the raw dataset used for the analysis.
- **`ფინალური პროექტი -pipeline.ipynb`** (*Final Project – pipeline.ipynb*) — the data pipeline notebook: loading, cleaning, and transforming the raw data before analysis.
- **`Final Project - Nino Gonjilashvili Dashboard.lvdash-2.json`** — a Databricks Lakeview dashboard built on the processed data.

## Tools & skills

- SQL / Databricks SQL
- Python (Jupyter notebook)
- Data cleaning and preparation
- Dashboard design and data visualization (Databricks Lakeview)

## Background

Built as the capstone project for TBC IT Academy's GetData program, applying SQL, data preparation, and dashboarding skills to a real-world dataset from start to finish.
